## 📖 Overview
SecureVault is a modern web application built to handle task management securely and efficiently. By separating the client interface and the server logic into a structured Frontend and Backend architecture, this portal ensures a seamless user experience backed by a robust and protected API.

## ✨ Key Features
* **Full-Stack Architecture:** Clean separation of concerns between the user interface and backend logic.
* **Modern Frontend UI:** Lightning-fast, responsive interface built with Vite and React.
* **Serverless Backend:** High-performance, low-latency API endpoints managed via Cloudflare Workers.
* **Security-First Approach:** Implements secure routing, data validation, and safe state management.

## 💻 Tech Stack
* **Frontend:** Vite, React.js (JavaScript/JSX)
* **Backend:** Node.js, Cloudflare Workers (Wrangler)
* **Version Control:** Git & GitHub
